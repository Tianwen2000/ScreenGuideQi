## 网络条件与结果边界

本机访问 `workers.dev` 默认域名时 TLS 失败，系统解析到非预期地址。新 Pages 域名在本机曾返回 NXDOMAIN，而可信公共解析已返回 Cloudflare 地址。原因可能包括缓存或网络 DNS 限制，尚未完全定位。

公网验证对该测试进程临时指定正确解析地址，并保留完整 TLS 域名证书验证。它证明已部署网关与真实云端 DO 的 WSS 配对能工作，**不证明系统默认 DNS、两部手机网络或跨网视频已经通过**。APK 没有硬编码服务 IP，也没有改变系统 DNS 或要求 VPN。

后续系统默认 DNS 下 `/health` 已返回 HTTP 200，但重复公网测试仍观察到握手或消息阶段的间歇超时，因此公网稳定性未通过验收。App 为 TLS/HTTP 升级以及首次房间响应设置了超时，避免一直停留在“正在连接”。

OAuth 登录没有账单订阅读取权限；账单接口返回 403。使用的功能在 Free 计划支持范围内，没有调用付费套餐开通接口。账户当前套餐仍以控制台为准。
