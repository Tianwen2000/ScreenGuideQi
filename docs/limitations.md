# 已知限制

- 0.5.0 MVP 包含屏幕视频、全屏观看和指导端到共享端的单向语音。没有远程操作、系统音频采集、共享端麦克风采集或保存功能。
- 这是公网直连测试版。TURN 关闭，STUN 不保证穿透 CGNAT、UDP 限制或防火墙；无法直连时结束并提示换网重新配对。不会自动开通中继或计费。
- 默认 WSS 入口已部署，也通过过模拟器传输测试；历史测试出现过握手超时和中途断线。国内目标手机网络的可达性与持续稳定性仍须分别确认。WSS 成功不等于屏幕传输成功。
- 双模拟器媒体使用虚拟 Wi-Fi host/host 路径；不等于真实跨网 NAT 通过。Debug 合成音验证不等于真实手机的麦克风、扬声器、回声和音质验证。
- Android 10 起可安装，设备自动测试使用 Android 14 API 34。Android 10/其他版本、不同厂商、单个应用共享及 16 KB 页设备运行仍待真机验证；静态对齐检查不能代替设备测试。
- 共享页隐藏本机视频预览，避免全屏录屏产生递归小画面。指导端按实际帧尺寸等比显示，横竖屏会保留必要黑边。
- 屏幕共享无法绕过 FLAG_SECURE，银行、支付、DRM 等受保护页面可能黑屏。系统支持时使用原生单应用共享选择器。
- 通知权限拒绝时阻止开始录屏/开启麦克风，以保证有可见状态入口；仍可接收屏幕。再次允许可到系统应用权限设置。
- 麦克风默认关闭，仅指导端显式开启后请求权限和启动 microphone 前台服务。系统全局麦克风开关、其他通话或厂商限制可能使声音不可用；停止再开启可重试。
- 任一端锁屏或退出会结束协助。网络黑洞、进程终止的检测需要时间；文本心跳每 10 秒、45 秒无 pong 后本地结束，媒体已连接后的中断也有 10 秒清理倒计时。恢复网络不自动恢复采集。
- 一个 Hub 最多 5 个房间、32 条连接。按 IP 限制每小时创建 10 次、每分钟猜码/加入 5 次；不适合公开平台或压力测试。
- 协助码待配对有效 5 分钟；加入确认 1 分钟；接受后 2 分钟等待录屏；媒体协商服务端与客户端 90 秒；激活会话最长 1 小时。过期通过 alarm 清理，部署和运行时升级也可能中断连接。
- Cloudflare Workers/DO/Pages 使用免费能力，超额会不可用；没有调用套餐升级或付费 TURN 开通。OAuth 无账单订阅读取权限，不能把它当作账户当前套餐或未来价格永不变化的证明。
- Release 非调试，当前为自用覆盖安装沿用旧版调试签名。商店发布需要独立保护的正式签名和分发审核。

诊断只显示字节/帧/音频采样累计值和候选类型，不显示 IP 或完整报告。日志不记录协助码、身份凭据、SDP/ICE、屏幕或声音。不得在 APK 或仓库放置托管账户令牌和 TURN 长期密钥。
